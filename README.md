# TypeScript HTML Tailwind – Lightweight Homepage

My own personal minimal homepage project built with TypeScript, HTML, and Tailwind CSS. Designed to stay **under 14KB** total size — inspired by [this article](https://endtimes.dev/why-your-website-should-be-under-14kb-in-size/).

## ✨ Features

- ⚡ Ultra-lightweight – total payload under **14KB**
- 🎨 Built with **TypeScript**, **HTML**, and **Tailwind CSS**
- 🎞️ Simple animation in the background with my own simple 3d rasterization implementation:
  Reference: [Scratchapixel – 2D Coordinates of 3D Points](https://www.scratchapixel.com/lessons/3d-basic-rendering/computing-pixel-coordinates-of-3d-point/mathematics-computing-2d-coordinates-of-3d-points.html)

## Getting Started

Install dependencies and build the project:

```bash
npm install
npm run build
```

to run localy after building:
`npx serve dist`
